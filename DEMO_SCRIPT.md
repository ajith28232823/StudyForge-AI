# 2–4 minute demo video script

**0:00–0:25 — Problem**
“Students often reread notes but still struggle to explain concepts or apply them. StudyForge helps turn existing notes into active learning.”

**0:25–0:45 — Introduce**
“This is StudyForge AI, built for the AI + Education track. I can paste class notes, choose my level, and choose a learning goal.”

**0:45–1:35 — Show it working**
Paste a short set of real class notes. Click “Forge my learning kit.” Open the Understand tab and explain the output. Then show Connect concepts, Practice, and Study plan.

**1:35–2:10 — Technical approach**
“The app uses Python and Streamlit. With a Gemini API key, generative AI creates tailored learning materials. Without a key, a local text-analysis fallback demonstrates the workflow. The app can export a Markdown learning kit.”

**2:10–2:35 — Impact and limitations**
“It supports active recall and concept connections. AI output must be checked against course material, and the fallback is deliberately labelled as text analysis.”

**2:35–2:50 — Closing**
“StudyForge aims to help students move from memorizing notes to understanding and applying ideas.”

Record the actual running app; do not claim features you have not tested.
